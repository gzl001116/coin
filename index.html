中央点数服务

这里负责账号、充值和点数消费记录管理。

数据展示规则
中央点数网站：不显示用户当前点数余额。
中央点数网站：不显示用户充值记录。
中央点数网站：不显示用户消费点数记录。
商城网站：显示用户当前点数余额。
余额和完整账务数据仍由中央系统内部保存，并通过授权 API 提供给商城网站。

点数规则

充值获得的点数只能消费，不能提现。只有业务站产生的作者/卖家收入才可以结算提现。

充值

规则：实际支付金额的 3% 被扣除，剩余 97% 进入钱包。

请输入金额并计算。

用户记录展示规则

中央点数网站不显示用户充值记录，也不显示用户消费点数记录。

充值记录：不显示
消费点数记录：不显示
当前点数余额：不显示

用户当前余额只在商城等业务网站显示。

卖家财务不在中央点数网站展示

卖家应在对应的商城网站查看自己的累计收入、待结算收入、可结算金额、提现记录和 5% 手续费。中央点数网站不展示这些卖家财务数据。

商城网站：显示卖家收入 / 可结算金额 / 手续费 / 提现状态
中央点数网站：不显示卖家财务金额

站长接入

只有已验证的网站站长可以连接业务站。连接成功后，该站点使用统一账号中心，用户只需登录一次即可访问已接入的网站。

接入权限仅站长
登录方式SSO 单点登录
用户体验登录一次
尚未连接。普通用户没有网站连接权限。

已连接网站

示例漫画站 manga.example.com已连接 · SSO

统一登录

用户在任意已连接网站登录后，由统一账号中心签发登录会话。跳转到其他已连接网站时自动建立登录状态，无需再次输入账号密码。

统一账号 → SSO 会话 → 小说站 / 漫画站 / AI站
业务站不能自行创建或修改统一账号密码。

商城余额展示

商城网站通过授权钱包 API 读取用户当前点数余额。中央点数网站不展示这个余额。

中央点数网站：余额不显示
商城网站：显示当前点数余额

充值扣除比例3%
卖家提现佣金5%
